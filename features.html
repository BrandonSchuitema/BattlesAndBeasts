This section of the site is for all the extra features contained around the game. Like online tools to better help the player with their gaming experience, or more information about the game outside of the rule book.

Shop and Inventory Tool

The amazing Binky Times used his magical powers in Unity (Game Engine) to create a cool little tool for player's to use. This tool has all items in the game within shops that the player can interact with. The tool also keeps track of the player's current income within the game. Lastly, the game keeps track of the player's inventory as well.
